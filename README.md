Student Task Tracker 📚

A simple, responsive web application that helps students organize their tasks, manage deadlines, and track their progress.

🔗 Live Demo: https://belovedgem46-a11y.github.io/student-task-tracker/

✨ Features

- ➕ Add new tasks
- 📅 Set optional task dates
- ✅ Mark tasks as completed or undo completion
- 🗑️ Delete tasks
- 📊 View task statistics
- 💾 Save tasks in the browser using local storage
- 📱 Responsive interface for different screen sizes

🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

🚀 How to Use

1. Open the "live application" (https://belovedgem46-a11y.github.io/student-task-tracker/).
2. Add a task and optionally choose a date.
3. Mark tasks as completed when you finish them.
4. Delete tasks you no longer need.

Your tasks are saved in your browser's local storage.
